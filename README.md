# DesignBazzar V31 — User Character + Draggable Hero Designs

This version updates the hero section with the user's supplied character cutout and a subtle lower-body blur/fade for background blending.

## Hero changes
- Uses `public/assets/hero-character-user.png` as the hero character.
- Adds a soft blurred duplicate only at the lower edge of the character.
- All three hero design cards can be dragged anywhere within the hero area.
- Dragging is constrained to the hero section and does not open the project modal.
- Clicking a card without dragging still opens the full design view.
- Existing desktop/mobile layout and social links are preserved.

## Run
```bash
npm install
npm run dev
```
